# SE-2.1-2.2-LU2

This repository contains the code, notebooks, and datasets for LU2 of the module "ATIx Informatica 2.1/2.2 Full-Stack Web Applications with AI".

## Project context

This assignment focuses on developing a working prototype in pairs that demonstrates how AI and data analysis can add value to solving real-world problems.

The project follows the full data science cycle:
- define a relevant problem
- work with a dataset provided by a client or stakeholder
- set up a safe and privacy-friendly development environment
- perform exploratory data analysis (EDA) to explore, clean, and analyze the data
- select relevant variables
- train and optimize a suitable AI model
- critically assess whether AI is the right tool for the problem
- carry out a preliminary risk classification according to the EU AI Act (2025)
- establish clear ethical frameworks
- propose technical integration of the model into a web application
- design a human-centered AI system that supports users in data-driven decisions

The work is documented carefully and results in a prototype that is not only technically functional, but also responsible, transparent, and useful in a practical context.

## Summary of the assignment

Students work in pairs to develop a working prototype that shows how AI and data analysis can create value when solving real problems. The process follows the complete data science lifecycle: defining a relevant issue, working with a client dataset, setting up a secure and privacy-aware development environment, and conducting Exploratory Data Analysis (EDA) to explore, clean, and analyze the data.

After that, students select relevant variables, train and optimize an appropriate AI model, and critically evaluate whether AI is the correct method for addressing the problem. They also perform a preliminary risk classification under the EU AI Act (2025) and define clear ethical guidelines.

Finally, they develop a proposal for integrating the model into a web application and design a human-centered AI system that supports users in making data-driven decisions. The final outcome is a well-documented prototype that is technically effective, transparent, ethically responsible, and practical for real-world use.
